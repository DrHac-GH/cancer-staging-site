# M0 の検収手引き

作業ブランチ `m0-data-driven` の内容を、公開（main へ反映）してよいか確認するための手引きです。
公開中のサイトはまだ変わっていません。所要の目安は合計 40〜60 分です。

## 準備（1 分）

```bash
cd ~/Desktop/Claude/アプリ開発/cancer-staging-site && python3 -m http.server 8765
```

ブラウザで http://localhost:8765/ を開きます（すでに動いていればそのまま開けます）。

## 見る順

### 1. 画面の動き（10 分）

- ホーム → 各癌腫の情報ページ → ツール、の順に一巡する。右上の言語切替で英語も見る。
- ツール: 因子を選ぶとステージが出る。判定結果は公開中のサイトと同じ（食道を除く）。
- 情報ページ: 因子の説明とステージ表が出る。表はツールと同じデータから作っている。
- 各ページの下: 出典・準拠版・免責。新版が出ている系統には「未反映」の注記が付く。
- http://localhost:8765/changelog.html : 準拠版の一覧と変更履歴。

見てほしい点: 表示の崩れ、分かりにくい言い回し、出典・免責の文面（`data/editions.json` の `disclaimer`）。

### 2. 選択肢の要約（15〜20 分）

[label-review.md](label-review.md) に、旧サイトの表記と現在の要約を全系統ぶん並べています。

見てほしい点: 要約で意味が変わっていないか、落ちた条件がないか。直したい行は選択肢名と文言を
伝えてもらえれば直します。胃・肝（規約）・膵・UICC の各系統は、このあとの版改訂（M1〜M4）で
ラベルも見直すので、明らかな誤りだけで構いません。

### 3. 食道癌 第12版（10〜15 分）

[diff/esophagus-12.md](diff/esophagus-12.md) に、旧サイトとの違いと第12版の表を書いています。
学会公式の英訳版を根拠に反映済みです（書籍との照合は未了）。

- 情報ページ http://localhost:8765/esophagus/index.html の表が、差分表の 2 つの表と同じか。
- ツール（臨床）http://localhost:8765/esophagus/tool.html と（病理）http://localhost:8765/esophagus/p_tool.html 。
- 差分表の末尾「検収で確認していただきたい点」。

### 4. 判定の疑義（5 分・裁定）

M0 では挙動を変えていません。書籍での確認をお願いします。

| 項目 | 現状 | 確認したいこと |
|---|---|---|
| 大腸 T4b でリンパ節転移あり（M0） | **裁定済み・修正済み**（5 通りとも IIIC・[diff/colorectal-9-t4b.md](diff/colorectal-9-t4b.md)） | 画面で T4b N1a M0 などが IIIC になること |
| 胃 病理分類 | Web 版の表は接合部腺癌の表（胃15準拠・食道の英訳版 Table 10）と全マス一致 | ネイティブ版の表が違う（T3 N0・T3 N1・T4b N3a）。胃16の検収で合わせて確認 |

### 5. 情報ページから外した本文（5 分・裁定）

版数入りか、定義文に近い文だったため外しました。必要なものは要約で戻します。

- 膵「第8版での主な変更点」の節
- 食道の注意書き（組織型や時期で分類が異なる旨）
- 胆嚢の所属リンパ節の範囲の一文
- 各ページ冒頭の「規約は UICC に準拠している」旨の説明
